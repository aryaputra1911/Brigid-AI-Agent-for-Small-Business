# Phase 2: Integrasi Logo & Aset Brand Brigid

Tanggal: 2026-11-15 | Branch: `checkreview` | Referensi plan: `docs/BRIGID_PLAN.md` §7.3 (baris 199-207)

## Lingkup

Integrasi logo Brigid yang sudah disetujui pemilik (`frontend/public/brand/brigid.svg`)
menggantikan seluruh aset logo era Wali (`wali.svg`, `wali-180.png`, `wali.lottie`,
`lib/wali-logo-animation.json`) beserta komponen dan animasinya. Tidak ada fitur baru.

## Perubahan kode

- `components/ui/wali-logo.tsx` menjadi `components/ui/brigid-logo.tsx`: `WaliLogo` menjadi
  `BrigidLogo`, aria-label "Brigid", fallback `/brand/brigid.svg`, API komponen tetap
  (`state?: "idle" | "processing" | "reply"`, `className`, `decorative`).
- Animasi Lottie (`lottie-web` + `lib/wali-logo-animation.json` + `lib/lottie-light.d.ts`)
  diganti animasi CSS: keyframes `brigid-processing` (pulse loop 1,4s saat menunggu balasan)
  dan `brigid-reply` (satu pulsa 0,9s saat balasan tiba, lalu kembali ke transform statis).
  Komponen kini murni turunan props tanpa state dan tanpa loader runtime.
- `app/layout.tsx`: `metadata.icons.icon` ke `/brand/brigid.svg` + `/favicon.ico`,
  `metadata.icons.apple` ke `/brand/brigid-180.png`.
- `workspace.css` dan `landing.css`: class `.wali-logo*` menjadi `.brigid-logo*`; keyframes
  dibungkus `@media (prefers-reduced-motion: no-preference)` selain gerbang reduced-motion di
  komponen.
- Referensi `/brand/wali.svg` di `landing-page.tsx` dan `landing-interactions.tsx` diganti.
- `scripts/verify-loading.cjs`: asersi pergerakan nyata mark (bukan hanya deklarasi animasi),
  loop processing, satu pulsa reply yang menyelesaikan diri, link ikon, dan status aset brigid.
- Dokumen `README.md`, `DESIGN.md`, `DELIVERY-GATE.md` diperbarui pada paragraf yang
  mendeskripsikan logo/animasi lama.
- Dependensi `lottie-web` dihapus dari `package.json` dan lockfile.

## Keterbatasan

- `npm run test:loading` tidak dapat dijalankan di lingkungan kerja ini: skrip memakai
  channel Chrome yang tidak terpasang, dan pemasangan dependensi sistem Chromium butuh sudo
  yang tidak tersedia. Skrip sudah diperbarui dan perlu dijalankan di lingkungan dengan
  Chrome sebelum merge.
- Maskable mengikuti definisi safe-zone lingkaran web.dev; pada launcher persegi logo tampak
  lebih kecil karena seluruh konten berada di dalam lingkaran 80%.

## Revisi 1 (umpan balik review Tahap 2)

Tiga catatan review ditangani:

1. `brigid-maskable-512.png` dan laporan audit dianggap "belum ada". Keduanya sudah ada dan
   ter-commit di `76f314b`. Pengukuran juga menunjukkan `brigid-512.png` sudah konsisten
   dengan 180/192 (konten 487/512 px, 95% kanvas; padding sisanya `#070806` yang menyambung
   dengan border artwork). Yang ber-padding lebar adalah maskable (281x296 di tengah 512),
   sesuai fungsinya.
2. Kualitas teknis SVG. `brigid.svg` dan `brigid-mono.svg` di-trace ulang dari master
   `brigid.png` dengan visioncortex VTracer:
   - `brigid.svg`: mode cutout, 250 path, 197 KB (dari 336 KB, minus 41%), tanpa path
     background solid full-canvas (margin kanvas kini transparan), plus `viewBox`.
     Mode `stacked` dicoba lebih dulu tetapi dibuang: pada mode stacked area gelap artwork
     adalah lubang di path terang yang menampakkan path dasar, sehingga menghapus path dasar
     merusak render. Mode cutout membuat tiap region berdiri sendiri.
   - `brigid-mono.svg`: trace binary, 29 path, 145 KB (dari 336 KB), satu warna adaptif
     `currentColor` menggantikan `#000000`/`#FFFFFF` hardcoded; lubangnya benar-benar
     transparan sehingga tampil benar di permukaan terang maupun gelap.
   - Semua PNG (180/192/512, maskable) dan `favicon.ico` dirender ulang dari master baru.
3. Laporan audit: file ini.

Verifikasi ulang: typecheck, lint, format:check, test:unit 12/12, build hijau; server
production menyajikan ketujuh aset dengan 200 dan link ikon ada di `<head>`.
Catatan review "~161 KB" sesuai ukuran gzip dari trace lama; ukuran file baru 197 KB
(gzip lebih kecil lagi).
