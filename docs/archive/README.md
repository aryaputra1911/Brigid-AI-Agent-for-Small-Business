# Arsip era Wali

Dokumen di folder ini berasal dari masa proyek bernama **Wali** (FinTechathon 2026,
International AI Track), sebelum rebranding menjadi Brigid. Semuanya dipertahankan apa
adanya dan **tidak di-rebrand**, supaya tetap akurat sebagai catatan sejarah.

| Dokumen | Isi |
| --- | --- |
| `PROJECT_AUDIT.md` | Serah terima audit proyek Wali (2026-10-15) |
| `FINALIZATION_PLAN.md` | Rencana finalisasi era Wali |
| `audit/` | Audit kode 4 tahap (17-18 Oktober 2026): laporan tes, review, perbaikan, verifikasi akhir |
| `results/` | Hasil evaluasi era Wali dengan model sungguhan |

Angka evaluasi di `results/` hanya berlaku untuk kode saat itu. Untuk kode sekarang,
jalankan `make eval` ulang sebelum mengutip angka.
